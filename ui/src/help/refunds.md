# Refunds

Money going back to cards and banks. *Initiated* and *pending* refunds are still with the provider; *processed* ones have reached the customer.

![The refunds list](refunds.png)

- Filter by **Status**; the sidebar **Product** filter also applies.
- **Reason** is the code chosen when the refund was made. **Failure** explains a refund the provider refused.
- Click a row to open the **payment** it belongs to. Refunds are shown there in context, next to the payment's timeline.

Refunds are created from a payment or an order, not from this page.
